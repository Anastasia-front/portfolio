# Privzeta dokumentacija Next.js

To je [Next.js](https://nextjs.org/) projekt ustvarjen z [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Začetek

Najprej zaženite razvojni strežnik:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Odprite [http://localhost:3000](http://localhost:3000) v brskalniku za ogled rezultata.

Stran lahko začnete urejati z `app/page.tsx`. Stran se bo samodejno osveževala med urejanjem.

Projekt uporablja [`next/font`](https://nextjs.org/docs/basic-features/font-optimization) za optimizacijo in avtomatsko nalaganje pisave Geologica iz Googla.

## Več informacij

Za več informacij o Next.js poglejte:

- [Next.js dokumentacija](https://nextjs.org/docs) - informacije o funkcionalnostih in API-ju Next.js.
- [Learn Next.js](https://nextjs.org/learn) - interaktivni tečaj Next.js.

Lahko si ogledate tudi [Next.js GitHub repozitorij](https://github.com/vercel/next.js/) - vaši prispevki in povratne informacije so dobrodošli!

## Namestitev na Vercel

Najlažji način za nameščanje vaše Next.js aplikacije je uporaba [platforme Vercel](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme).

Za več podrobnosti preberite [dokumentacijo o nameščanju Next.js](https://nextjs.org/docs/deployment).
