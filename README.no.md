## Implementert funksjonalitet i prosjektet

- SEO
- Navigasjon på nettstedet
- Temabytting
- Responsivt design
- Ulike bildegallerier/slidere
- Forbedret tilgjengelighet
- Optimalisert lasting av ressurser
- Lokalisering og internasjonalisering (L10n og i18n)
- Skjemainnsending med validering
- Enkel innholdsstyring (all tekst er i lang.json-filer)
